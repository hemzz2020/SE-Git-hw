🧭 Project Summary
This repository showcases the core principles of using Git and GitHub for version control and collaborative development. The project walks through the complete workflow, demonstrating how developers manage changes, review updates, and coordinate work in a shared environment.

The assignment covers:

Setting up and configuring a GitHub repository

Creating an initial commit with a basic program

Developing new features through branches

Using pull requests for peer review and merging

Introducing and resolving merge conflicts

Updating documentation and tracking tasks with GitHub Issues
